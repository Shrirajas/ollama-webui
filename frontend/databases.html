    How it is kept safe

    • Only queries that read are run. Anything that could change the database is refused before it is sent, and the connection itself is opened read-only.
    • Only models on this machine are used. Rows never go to a cloud model.
    • Passwords stay on the server. They are never sent back to this page.
    • Still, give the app a database user that can only read.
